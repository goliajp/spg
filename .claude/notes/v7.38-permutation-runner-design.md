## 1. 目标 / 约束

### 必须达到
1. **一份 corpus N× 跑** — 5+ permutation 共用同一份 sqllogictest fixture,**不许 copy-paste**
2. **dev cycle 不退化** — 默认 `cargo test` 只跑 `embedded` permutation;其它 permutation 显式触发
3. **`gate.sh` fast tier ≤ 90s e2e 子预算** — 跑 3 核心 permutation(`embedded` / `server_simple` / `server_extended`)
4. **`gate.sh --full` 全跑** — 5 核心 + sanitizer / debug-asserts / release / hot_only 共 8+
5. **退路简单** — 失败时一眼看出哪个 permutation × 哪个 fixture × 第几行
6. **进程隔离** — 一个 permutation crash 不污染下一个(env var-driven 子进程 fork)

### 不允许的形态
- ✗ 一个 cargo test 内部循环跑 N permutation — engine 全局 static / thread-local plan cache 不易复位,污染风险
- ✗ macro 展开成 N 个 `#[test]` — corpus ~1000 条 × 5 permutation = 5000 testcase 进 `cargo test` 默认 = dev cycle 爆
- ✗ shell 脚本 — TOML 改一行不能触发 lint,失败粒度不够细
- ✗ 跑 corpus 时再加锁 / 加 mutex — 直接 fork 子进程绕过

### 3.2 Schema 解析(`src/config.rs`)

```rust
#[derive(serde::Deserialize, Debug)]
pub struct PermFile {
    pub default: DefaultCfg,
    #[serde(rename = "permutation")]
    pub permutations: Vec<Permutation>,
}

#[derive(serde::Deserialize, Debug)]
pub struct DefaultCfg {
    pub corpus_root: PathBuf,
    pub include_globs: Vec<String>,
    pub exclude_globs: Vec<String>,
    pub fast_tier_sample: Option<String>,
    pub fast_tier: Vec<String>,
    pub timeout_per_file_secs: u64,
}

#[derive(serde::Deserialize, Debug)]
pub struct Permutation {
    pub name: String,
    pub mode: Mode,                          // "embedded" | "server"
    #[serde(default)]
    pub env: BTreeMap<String, String>,
    #[serde(default)]
    pub require_features: Vec<String>,
    #[serde(default)]
    pub full_only: bool,
    #[serde(default)]
    pub build_flags: Vec<String>,
    #[serde(default = "default_profile")]
    pub build_profile: String,               // "release" | "dev"
}

#[derive(serde::Deserialize, Debug, Clone, Copy)]
#[serde(rename_all = "snake_case")]
pub enum Mode { Embedded, Server }

fn default_profile() -> String { "release".into() }
```

## 4. Runner CLI

### 4.1 `clap` 接口

```
spg-perm-runner — v7.38 permutation matrix runner

USAGE:
  spg-perm-runner <COMMAND>

COMMANDS:
  list                  List all permutations defined in tests/permutations.toml
  verify                Parse TOML, validate require_features, no execution
  run --permutation N   Run one named permutation against the corpus
  all [--fast | --full] Run multiple permutations; --fast = fast_tier subset
  report                Print last run's three-column report (embedded / SPGS / SPGE)

FLAGS:
  --corpus PATH         Override default corpus root
  --include GLOB        Override include glob (repeatable)
  --jobs N              Parallel fixture jobs per permutation (default = nproc/2)
  --timeout SECS        Override per-file timeout
  --bail                Stop at first failure (default = collect all)
  -v / --verbose        Print every fixture as it runs
```

### 4.2 子命令语义

- `list` — read TOML, print one row per permutation: name / mode / env / full_only
- `verify` — TOML parse + require_features 检查(eg. `extended-protocol` 要求 sqlx feature 开)+ corpus globs 解析正常,**不跑测试**。fast (<1s),CI 第一步
- `run --permutation embedded` — fork 单 permutation,跑全 corpus
- `all --fast` — 跑 `default.fast_tier`(3 个),每个 permutation 跑 `fast_tier_sample` 子集
- `all --full` — 跑全部 permutations(含 `full_only = true`),每个跑全 corpus
- `report` — 读上次 run 的 `target/perm-runner/report.json`,打印三栏对照

### 4.3 默认值(fast tier 内置预算)

| Flag | Default | --fast | --full |
|---|---|---|---|
| permutations | all (non-full_only) | `fast_tier` only | all |
| corpus 范围 | include_globs | `fast_tier_sample` | include_globs |
| timeout_per_file | 30s | 10s | 60s |
| jobs | nproc / 2 | nproc | 1 (sanitizer noise control) |

## 5. Process isolation 设计

### 5.1 fork sub-process per permutation(推荐方案)

```
parent (spg-perm-runner)
  ├── reads tests/permutations.toml
  ├── for each permutation P:
  │     fork child:
  │       env = parent_env ∪ P.env ∪ { SPG_PERMUTATION_NAME = P.name }
  │       exec spg-perm-runner-child --permutation P.name --corpus ...
  │       wait, collect stdout/stderr/exit, parse report.json fragment
  └── aggregate to target/perm-runner/report.json
```

**为什么 fork 子进程** —
- engine state(plan_cache、catalog、tracing subscriber、tokio runtime)在多个 permutation 间 reset 困难,fork 直接清零
- panic 不污染下一个 permutation
- 真实 env var 切换语义(`SPG_FORCE_SIMPLE_QUERY=1` 在主进程内改可能改不到已 cached 的决策点)
- 失败 isolation:某个 permutation hang → SIGTERM 该 child,parent 继续

### 5.2 子进程入口(`src/child.rs`)

```rust
// spg-perm-runner-child 是 spg-perm-runner 同二进制,通过 SPG_PERMUTATION_NAME env 判定
pub fn child_entry(args: ChildArgs) -> Result<()> {
    let perm_name = std::env::var("SPG_PERMUTATION_NAME")
        .context("child invoked without SPG_PERMUTATION_NAME")?;
    let cfg = load_perm(&perm_name)?;

    let runner: Box<dyn FixtureRunner> = match cfg.mode {
        Mode::Embedded => Box::new(EmbeddedRunner::new()?),
        Mode::Server => Box::new(ServerRunner::new(perm_name.contains("extended"))?),
    };

    let mut report = PermReport::new(&perm_name);
    for fixture in discover_corpus(&args.corpus, &args.includes, &args.excludes)? {
        let res = runner.run_fixture(&fixture, Duration::from_secs(args.timeout))?;
        report.push(fixture, res);
        if args.bail && report.last_failed() { break; }
    }
    report.write_json(format!("target/perm-runner/{perm_name}.json"))?;
    Ok(())
}

trait FixtureRunner {
    fn run_fixture(&mut self, path: &Path, timeout: Duration) -> Result<FixtureResult>;
}

struct EmbeddedRunner { engine: spg_engine::Database }
struct ServerRunner   { client: PgConnection, _server_handle: JoinHandle<()> }
```

### 5.3 单进程退路(performance escape hatch)

如果将来发现 fork overhead 太重(unlikely:fork + exec 是 ~5ms,跟 corpus 跑一条 .slt 同量级),
加 `--single-process` flag 退到原地循环模式 —— 但**不允许在 default code path**,留作 escape hatch。

### 6.2 discovery 算法(`src/corpus.rs`)

```rust
pub fn discover_corpus(
    root: &Path,
    include_globs: &[String],
    exclude_globs: &[String],
) -> Result<Vec<PathBuf>> {
    let inc: Vec<glob::Pattern> = include_globs.iter().map(|g| glob::Pattern::new(g)).try_collect()?;
    let exc: Vec<glob::Pattern> = exclude_globs.iter().map(|g| glob::Pattern::new(g)).try_collect()?;
    let mut out = Vec::new();
    for entry in WalkDir::new(root) {
        let entry = entry?;
        if entry.file_type().is_file() && entry.path().extension() == Some("slt".as_ref()) {
            let rel = entry.path().strip_prefix(root)?;
            let s = rel.to_string_lossy();
            if inc.iter().any(|p| p.matches(&s)) && !exc.iter().any(|p| p.matches(&s)) {
                out.push(entry.into_path());
            }
        }
    }
    out.sort();   // deterministic order = deterministic report
    Ok(out)
}
```

### 6.3 fixture 元数据(per-file directive)

复用现有 sqllogictest runner 的 directive 语法 + DuckDB 扩展(已在 plan §二 轴 1 引入):

```
# Sample directive lines that runner respects (cooperative with permutation runner)
# permutation_skip: server_extended      # Skip this permutation on this fixture
# permutation_only: embedded             # Only embedded mode
# requires_env: SPG_TEST_ALLOW_FOO=1     # Skip unless env present
# requires_feature: jsonb                # Skip unless feature in binary
```

Runner reads first 20 lines of each `.slt`,解析 `# permutation_skip:` / `# permutation_only:`,据此过滤。
不识别的 directive = warn,**不 fail**(forward-compat,跟工艺 §三 #10 `require <ext>` 同精神)。

## 7. gate.sh 集成

### 7.1 fast tier(默认)

`scripts/gate.sh e2e` 调用:
```bash
cargo run -p spg-perm-runner --release -- all --fast --corpus xtests/sqllogictest/corpus
# 预算:90s(plan §六 fast tier per-category)
```

`all --fast` 默认覆盖:
- 3 个 permutation × `fast_tier_sample` (~50 fixtures) × 1 perm = 150 fixture runs
- 在 mini 上预估 30-60s,fits 90s 子预算

### 7.2 full tier(`--full`)

`scripts/gate.sh e2e --full` 调用:
```bash
cargo run -p spg-perm-runner --release -- all --full --corpus xtests/sqllogictest/corpus
# 无时间上限,可跑 8 permutation × ~1000 fixtures = 8000 runs
```

### 7.3 失败时报告路径

每个 child 写 `target/perm-runner/<perm>.json`,parent merge 到 `target/perm-runner/report.json`:

```json
{
  "permutations": [
    {
      "name": "embedded",
      "passed": 47,
      "failed": 3,
      "skipped": 0,
      "failures": [
        {
          "fixture": "spg_baseline/12_subquery.slt",
          "line": 142,
          "expected": "...",
          "actual": "...",
          "duration_ms": 23
        }
      ]
    }
  ]
}
```

`spg-perm-runner report` 打印三栏:`fixture | embedded | server_simple | server_extended`,
unicode green check / red cross,失败 fixture 链接到 line。
