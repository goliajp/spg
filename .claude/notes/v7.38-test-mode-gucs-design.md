## 1. 目标 / 约束

### 必须达到
1. **8 个 GUC 接进 engine**(plan §一 D 列 7 + skeleton §1.D 加 prefetch = 8)
2. **每个 GUC 一处明确 acceptor file:line** — `xtests/sigil/test-mode-gucs.md` 索引表强制 fill
3. **每个 GUC 一条 unit test** 验证关掉对应 surface(决定性变化能被测试看到)
4. **release build 零成本** — env var 只读一次缓存,hot path 是 `bool` field 读取
5. **flake 不靠 `#[ignore]` 也不靠 retry** — flaky test 默认先看是不是该加 GUC(plan §一 D 铁律)
6. **三栏(embedded / SPGS / SPGE)同输出** — GUC 关掉 surface 后,三 permutation 结果字节相等

### 不允许的形态
- ✗ env var 在 hot path 每行读 — `std::env::var()` 是 syscall + lock,>100ns
- ✗ feature gate — 测试 build 不应该跟 release 不同二进制
- ✗ 加一个 GUC 就 fork 一份 engine fn — 单一 acceptor 跟 default behaviour 分流
- ✗ flake 用 `#[ignore]` 或 retry 绕 — plan §一 D 铁律,直接 fail review

## 2. GUC 形态选择(EnvConfig 模式)

### 2.1 决策:env-var-resolver per-engine-instance,启动时 freeze

**理由**:
- 一次性读 env 在 `Engine::new()` / `Database::open_path()`,后续 hot path 直接读 struct field
- 同一进程内多 engine 多 GUC 设值不影响 — 每个 engine 实例 freeze 自己的快照
- 真实 prod release build:GUC 全 default = `EnvConfig::default()` 是 const,零分配,优化器看穿

### 2.2 类型设计

```rust
// crates/spg-engine/src/testkit/env_config.rs (NEW file)

/// Frozen snapshot of test-mode GUCs read once at engine init.
///
/// Production code paths read fields directly via `engine.env_cfg().<field>`.
/// All fields default to "production" behaviour; only flips when env var set.
#[derive(Debug, Clone)]
pub struct EnvConfig {
    /// SPG_TEST_COMPUTE_QUERY_ID=regress — query id elided from EXPLAIN
    pub compute_query_id: ComputeQueryId,

    /// SPG_TEST_EXPLAIN_NO_COSTS=1 — EXPLAIN suppresses cost annotations
    pub explain_no_costs: bool,

    /// SPG_TEST_STATS_FROZEN=1 — ANALYZE-snapshot frozen, no auto-refresh
    pub stats_frozen: bool,

    /// SPG_TEST_PLAN_DETERMINISTIC=1 — disable cost-based decisions; lexical fallback
    pub plan_deterministic: bool,

    /// SPG_TEST_DISABLE_TOPK=1 — disable aggregate top-K LIMIT path
    pub disable_topk: bool,

    /// SPG_TEST_DISABLE_JOINFOLD=1 — disable v7.37 joinfold rewrite
    pub disable_joinfold: bool,

    /// SPG_TEST_RANDOM_SEED=N — seed any nondeterministic source
    pub random_seed: Option<u64>,

    /// SPG_TEST_PREFETCH_DETERMINISTIC=1 — pin prefetch threshold (e2e_prefetch flake)
    pub prefetch_deterministic: bool,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum ComputeQueryId {
    /// Production: hash & emit query id in EXPLAIN
    Auto,
    /// Test mode: elide query id from EXPLAIN output
    Regress,
}

impl Default for EnvConfig {
    fn default() -> Self {
        Self {
            compute_query_id: ComputeQueryId::Auto,
            explain_no_costs: false,
            stats_frozen: false,
            plan_deterministic: false,
            disable_topk: false,
            disable_joinfold: false,
            random_seed: None,
            prefetch_deterministic: false,
        }
    }
}

impl EnvConfig {
    /// Read all `SPG_TEST_*` env vars exactly once. Called by `Engine::new()`.
    pub fn from_env() -> Self {
        let mut cfg = Self::default();
        if let Ok(v) = std::env::var("SPG_TEST_COMPUTE_QUERY_ID") {
            cfg.compute_query_id = match v.as_str() {
                "regress" => ComputeQueryId::Regress,
                _ => ComputeQueryId::Auto,
            };
        }
        if std::env::var("SPG_TEST_EXPLAIN_NO_COSTS").is_ok_and(|v| v == "1") {
            cfg.explain_no_costs = true;
        }
        if std::env::var("SPG_TEST_STATS_FROZEN").is_ok_and(|v| v == "1") {
            cfg.stats_frozen = true;
        }
        if std::env::var("SPG_TEST_PLAN_DETERMINISTIC").is_ok_and(|v| v == "1") {
            cfg.plan_deterministic = true;
        }
        if std::env::var("SPG_TEST_DISABLE_TOPK").is_ok_and(|v| v == "1") {
            cfg.disable_topk = true;
        }
        if std::env::var("SPG_TEST_DISABLE_JOINFOLD").is_ok_and(|v| v == "1") {
            cfg.disable_joinfold = true;
        }
        if let Ok(v) = std::env::var("SPG_TEST_RANDOM_SEED") {
            cfg.random_seed = v.parse().ok();
        }
        if std::env::var("SPG_TEST_PREFETCH_DETERMINISTIC").is_ok_and(|v| v == "1") {
            cfg.prefetch_deterministic = true;
        }
        cfg
    }

    /// Test helper — builder-style override for programmatic GUC injection.
    /// Used by sqllogictest runner / oracle runner that constructs engines
    /// without env vars.
    pub fn builder() -> EnvConfigBuilder { EnvConfigBuilder { cfg: Self::default() } }
}

pub struct EnvConfigBuilder { cfg: EnvConfig }
impl EnvConfigBuilder {
    pub fn explain_no_costs(mut self, v: bool) -> Self { self.cfg.explain_no_costs = v; self }
    pub fn random_seed(mut self, v: u64) -> Self { self.cfg.random_seed = Some(v); self }
    // ... one per field
    pub fn build(self) -> EnvConfig { self.cfg }
}
```

### 2.3 Engine 持有

```rust
// crates/spg-engine/src/lib.rs — Engine struct field

pub struct Engine {
    // ... existing fields ...
    env_cfg: EnvConfig,
    // ...
}

impl Engine {
    pub fn new_with_storage(storage: Storage) -> Self {
        Self {
            // ...
            env_cfg: EnvConfig::from_env(),
            // ...
        }
    }

    /// For tests / oracle / perm-runner constructing engines without env.
    pub fn new_with_env_cfg(storage: Storage, env_cfg: EnvConfig) -> Self {
        Self { /* ... */ env_cfg, /* ... */ }
    }

    pub fn env_cfg(&self) -> &EnvConfig { &self.env_cfg }
}
```

**release zero-cost 证明**:`EnvConfig::default()` 是 const-foldable;`env_cfg().disable_topk` 编译成
`engine.env_cfg.disable_topk` field load = 1 cycle;若 inlined 且 `env_cfg = false` const-known,
分支会被 const-prop 删掉。Production 二进制 disable_topk 路径就是不存在。

pub(crate) fn annotate_explain_lines(lines: &mut [String], total_rows: usize, engine: &Engine) {

### 3.4 `SPG_TEST_PLAN_DETERMINISTIC=1` — lexical fallback for cost decisions

**Acceptor 1**:`crates/spg-engine/src/plan_cache.rs` plan selection (cost-based)

```rust
fn pick_best_plan(candidates: &[Plan], engine: &Engine) -> Plan {
    if engine.env_cfg().plan_deterministic {
        // Lexical: stable hash of plan signature, pick smallest. Deterministic
        // regardless of stats / row count estimates.
        return candidates.iter().min_by_key(|p| p.signature_hash()).unwrap().clone();
    }
    candidates.iter().min_by_key(|p| p.estimated_cost_ns()).unwrap().clone()
}
```

**Acceptor 2**:join-order selection (search `crates/spg-engine/src/join.rs` for cost-based reorder)

### 3.7 `SPG_TEST_RANDOM_SEED=N` — deterministic randomness

**Acceptor**:`crates/spg-engine/src/clock.rs` + any HashMap construction site that needs random

```rust
// crates/spg-engine/src/clock.rs — already has clock abstraction
impl Engine {
    pub(crate) fn rng_seed(&self) -> u64 {
        self.env_cfg().random_seed.unwrap_or_else(|| {
            // Production: derive from instant-derived clock
            self.clock_now_ns()
        })
    }
}
```

Then any `HashMap::with_hasher` or `rand::thread_rng()` call site uses
`engine.rng_seed()` to seed.

### 3.8 `SPG_TEST_PREFETCH_DETERMINISTIC=1` — pin prefetch threshold

**Acceptor**:`crates/spg-storage/src/segment.rs` 或 `bloom.rs` sequential scan prefetch trigger

```rust
fn should_prefetch_next_segment(scanned_rows: usize, env_cfg: &EnvConfig) -> bool {
    if env_cfg.prefetch_deterministic {
        // Deterministic threshold — trigger exactly when scanned_rows == 1024
        return scanned_rows == 1024;
    }
    // Production: heuristic based on row scan rate / current segment size
    scanned_rows > current_segment_rows() / 2
}
```

(Note: spg-storage doesn't directly hold EnvConfig — pass via parameter from engine,
or share via small `prefetch_deterministic: bool` static set at engine init.)

## 5. Unit test 模板

每个 GUC 一个 unit test,统一模板。例:

```rust
// xtests/env_cfg_disable_topk.rs

use spg_engine::testkit::env_config::EnvConfig;
use spg_engine::Database;

#[test]
fn disable_topk_falls_back_to_full_sort() {
    // Two engines with same data: one TOPK on, one off.
    let cfg_on  = EnvConfig::default();           // production: TOPK on
    let cfg_off = EnvConfig::builder().disable_topk(true).build();

    let mut db_on  = Database::open_in_memory_with_env_cfg(cfg_on);
    let mut db_off = Database::open_in_memory_with_env_cfg(cfg_off);

    let setup = r#"
        CREATE TABLE m(thread_id BIGINT, sender TEXT, internal_date BIGINT);
        INSERT INTO m SELECT i % 50, 'u'||i, 100000 - i FROM generate_series(1, 5000) g(i);
    "#;
    db_on.execute(setup).unwrap();
    db_off.execute(setup).unwrap();

    let q = r#"
        SELECT thread_id, MAX(internal_date) FROM m
        GROUP BY thread_id ORDER BY MAX(internal_date) DESC LIMIT 10
    "#;
    let r_on  = db_on.query(q).unwrap();
    let r_off = db_off.query(q).unwrap();

    // CRITICAL: byte-equal output even though execution paths differ.
    assert_eq!(r_on.rows, r_off.rows,
        "TOPK on/off must produce identical results for ORDER BY ... LIMIT");

    // CRITICAL: but the *plan* differs.
    let plan_on = db_on.query("EXPLAIN " + q).unwrap();
    let plan_off = db_off.query("EXPLAIN " + q).unwrap();
    assert!(plan_on.rows[0][0].as_str().unwrap().contains("TopK"),
        "Production should use TopK path");
    assert!(!plan_off.rows[0][0].as_str().unwrap().contains("TopK"),
        "disable_topk must skip TopK path");
}
```
