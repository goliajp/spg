## 1. 目标 / 约束

### 必须达到
1. **三 oracle 都跑得起来** — PG18 / MySQL 8 / MariaDB 11,docker-compose 一键起
2. **同一份 SQL 跑 SPG + oracle,sort-then-byte-equal** — 不接受"近似" / "类型转一下"
3. **adjust_*() 归一化框架** — 已知合法差异(timestamp precision、whitespace、float repr)显式 allowlist
4. **YugabyteDB 三命名约定** — `port.<name>` / `orig.<name>` / `depd.<name>` runner 自动 dispatch
5. **fast tier 跳 docker** — fast 子预算 60s,docker 启动就破预算;改用 SPG-self differential 顶
6. **EXPECTED FAILURE 二分态** — 已知 SPG 偏差锁在 `.spg.out`,修好移走 = 退步立刻被捕(R32 例)

### 不允许的形态
- ✗ hash 比较或抽样 — 全等 byte diff(plan §三 工艺 #5)
- ✗ "PG / SPG 都返回 50 行,放过" — 50 行内容必须字节相等(after sort + adjust)
- ✗ docker 起在 fast tier — 启动 5-10s × 3 oracle = 15-30s + warm-up,fast 60s 子预算崩
- ✗ 跳过 MySQL / MariaDB("反正 dropin 主线是 PG")— v7.38 三方言全做完才 ship

## 4. adjust_*() 归一化框架

### 4.1 设计借鉴(plan §一 C 给出)

借 PG `pg_upgrade` `src/bin/pg_upgrade/dump.c` 的 `adjust_old_dumpfile()` 思路:
**已知合法差异**(版本演进 / 编码细节 / 平台差异)用 allowlist 显式处理,**未列入的差异 = 失败**。

### 4.2 `src/adjust.rs` skeleton

```rust
//! Normalize result-set bytes for cross-oracle compare.
//!
//! Each `adjust_*` function knows ONE specific category of legal difference.
//! Composition is the order in `Pipeline::default()`. Any unmatched diff
//! after the pipeline = real semantic discrepancy = test fail.

pub struct AdjustPipeline {
    steps: Vec<Box<dyn AdjustStep>>,
}

pub trait AdjustStep: Send + Sync {
    fn name(&self) -> &'static str;
    fn apply(&self, lines: &mut Vec<String>);
}

impl AdjustPipeline {
    pub fn default() -> Self {
        Self {
            steps: vec![
                Box::new(AdjustTimestampPrecision),
                Box::new(AdjustFloatRepr),
                Box::new(AdjustWhitespace),
                Box::new(AdjustNullDisplay),
                Box::new(AdjustOrderingViaSort),    // sort lines lexically — final step
            ],
        }
    }

    pub fn apply(&self, raw: String) -> String {
        let mut lines: Vec<String> = raw.lines().map(String::from).collect();
        for step in &self.steps {
            step.apply(&mut lines);
        }
        lines.join("\n")
    }
}

// ----- 具体 steps -----

/// PG returns `2026-06-22 12:34:56.789012`, MySQL strips trailing `.0`.
/// Normalize to 6 decimals.
struct AdjustTimestampPrecision;
impl AdjustStep for AdjustTimestampPrecision {
    fn name(&self) -> &'static str { "timestamp-precision" }
    fn apply(&self, lines: &mut Vec<String>) {
        let re = regex::Regex::new(
            r"\b(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})(\.\d{1,6})?\b"
        ).unwrap();
        for l in lines.iter_mut() {
            *l = re.replace_all(l, |c: &regex::Captures| {
                let base = &c[1];
                let frac = c.get(2).map(|m| {
                    let s = m.as_str();          // ".789"
                    let mut padded = String::from(s);
                    while padded.len() < 7 { padded.push('0'); }   // ".789000"
                    padded
                }).unwrap_or_else(|| ".000000".to_string());
                format!("{base}{frac}")
            }).into_owned();
        }
    }
}

/// PG `1.23e-5`, MySQL `0.0000123` for FLOAT. Force scientific for | x | < 1e-3.
struct AdjustFloatRepr;
impl AdjustStep for AdjustFloatRepr { /* ... */ }

/// PG aligns columns with spaces; MySQL uses tabs. Collapse runs.
struct AdjustWhitespace;
impl AdjustStep for AdjustWhitespace {
    fn name(&self) -> &'static str { "whitespace" }
    fn apply(&self, lines: &mut Vec<String>) {
        for l in lines.iter_mut() {
            *l = l.split_whitespace().collect::<Vec<_>>().join(" ");
        }
    }
}

/// PG `(null)`, MySQL `NULL`, MariaDB `NULL`. Canonicalize to `NULL`.
struct AdjustNullDisplay;

/// 最后一步:lexical sort — order-insensitive compare.
struct AdjustOrderingViaSort;
impl AdjustStep for AdjustOrderingViaSort {
    fn name(&self) -> &'static str { "ordering-via-sort" }
    fn apply(&self, lines: &mut Vec<String>) { lines.sort(); }
}
```

```
# oracle: skip_adjust: float-repr   # 关掉某个 step
```

## 5. 命名约定(YugabyteDB)

### 5.1 三类前缀

- `port.<name>.slt` — 从 PG `src/test/regress/sql/` port 过来的, expected 锁两份(PG + SPG)
- `orig.<name>.slt` — SPG 自家新增的 test, expected 锁一份(SPG only,oracle 跑过参考)
- `depd.<name>.slt` — 仅 setup,被别的 test depend(eg. 创建跨 fixture 共享的表/视图)

### 5.2 `src/naming.rs` dispatch

```rust
pub enum Kind { Port, Orig, Depd }

pub fn classify(path: &Path) -> Result<Kind> {
    let name = path.file_name().and_then(|n| n.to_str()).context("non-utf8 name")?;
    if name.starts_with("port.") { Ok(Kind::Port) }
    else if name.starts_with("orig.") { Ok(Kind::Orig) }
    else if name.starts_with("depd.") { Ok(Kind::Depd) }
    else { bail!("fixture {} missing port./orig./depd. prefix", name) }
}

pub fn expected_paths(fixture: &Path, oracle: Oracle) -> ExpectedPair {
    let stem = fixture.file_stem().unwrap().to_str().unwrap();
    let dir = fixture.parent().unwrap().join("../expected");
    let suffix = match oracle { Oracle::Pg18 => "pg", Oracle::Mysql => "mysql", Oracle::Mariadb => "mariadb" };
    ExpectedPair {
        oracle: dir.join(format!("{stem}.{suffix}.out")),
        spg: dir.join(format!("{stem}.spg.out")),
    }
}
```

### 5.3 EXPECTED FAILURE 标记

`.spg.out` 内首行注释标:
```
-- EXPECTED FAILURE: see backlog R32 outer-agg correlated subq dialect
-- This file lock-in's the current SPG behaviour. When SPG matches PG,
-- delete this file and the runner will require .pg.out instead.
```

Runner 行为:
- 若 `.spg.out` 存在 → 测 SPG 跟它 byte-equal,通则 PASS
- 若 `.spg.out` 不存在 → 测 SPG 跟 `.pg.out` byte-equal
- **若 `.spg.out` 存在且 SPG 现已和 PG 等价 → runner 报 "EXPECTED FAILURE no longer failing"** = 提醒删除 `.spg.out`,**视为 fail**(防 dead expected)

```
USAGE:
  spg-oracle-runner <COMMAND>

COMMANDS:

  report                  Print last run's three-column report

FLAGS:
  --corpus PATH           Override corpus root (default xtests/oracle/corpus)
  --bless                 Update expected/*.{pg,mysql,mariadb}.out on failure
                          (regenerate from the oracle's output)
  --jobs N                Parallel fixture jobs
  --bail                  Stop at first failure
```

### 6.1 主要子命令

- `docker up` — 起 docker compose,wait healthchecks(timeout 60s)
- `run --oracle pg18` — 串行(or `--jobs N` 并行)跑 corpus,每条 fixture:
  1. classify port / orig / depd
  2. 跑 SPG embedded 拿 result
  3. 跑 oracle 拿 result
  4. AdjustPipeline 两边都过
  5. byte-equal compare,失败用 `similar::TextDiff` 显示 unified diff
- `all` — 三 oracle 全跑一遍
- `self-diff` — fast tier 替代(详 §7)
- `--bless` — 把 oracle output 写回 expected/(初始化 corpus 用,不在 CI)

## 7. fast tier — SPG-self differential

### 7.1 motivation

fast tier 子预算 60s(plan §六 fast tier `biz` 类),docker 起 3 oracle 至少 30s + warm-up,
**fast tier 跑 docker oracle = 必破预算**。

补偿方案(plan §六 C 已写):**SPG-self differential** — 同一份 SQL 跑:
- `embedded` permutation
- `server_simple` permutation
- `server_extended` permutation

**三栏自洽** = near-oracle。
- 是不是真符合 PG 行为 → full tier 用 docker oracle 确认
- 但 SPG 内部三条 path 同输入同输出已经 cover 95% 的"是不是当前 commit 改坏了"

### 7.2 实现:复用元机制 B(permutation runner)

`spg-oracle-runner self-diff` 内部 spawn `spg-perm-runner all --fast`,
但传 `--bail-on-divergence`:三 permutation 中任两 output 字节不等 = fail。

```rust
pub fn self_diff(corpus: &Path) -> Result<()> {
    let fixtures = discover_corpus(corpus, &["**/*.slt".into()], &[])?;
    for fixture in fixtures {
        let r_emb = run_embedded(&fixture)?;
        let r_ssimple = run_server_simple(&fixture)?;
        let r_sext = run_server_extended(&fixture)?;

        let n_emb = ADJUST.apply(r_emb);
        let n_ssimple = ADJUST.apply(r_ssimple);
        let n_sext = ADJUST.apply(r_sext);

        if n_emb != n_ssimple || n_emb != n_sext {
            bail!("SPG-self differential diverged on {}:\n--- embedded\n{}\n--- server_simple\n{}\n--- server_extended\n{}",
                  fixture.display(), n_emb, n_ssimple, n_sext);
        }
    }
    Ok(())
}
```
